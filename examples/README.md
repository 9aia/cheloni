# Examples

Runnable example projects under `examples/`. Each folder is a small Cheloni CLI that uses the monorepo’s Vite+ toolchain (`vp install`, `vp run start`, `vp check`).

## Examples

- [File Converter](01-file-converter/README.md) — validation, type-safety, and option aliases
- [Task Manager](02-task-manager/README.md) — multiple commands and middleware with shared context
- [Benchmark](03-benchmark/README.md) — bequeath options, positional args, and a custom timing plugin
- [JSON Tool](04-json-tool/README.md) — file I/O, JSON parsing, and read/write subcommands
- [Task Runner](05-task-runner/README.md) — std config plugin, positional task name, and config in handlers
