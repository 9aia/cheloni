# Workflow Rules

- Before implementing, write new tests or update them. After implement the changes, run the tests to ensure they pass. Iterate until the tests pass. Finally, update or add new docs when applicable.
- At the end of a task, don't forget to update `project/`, `README.md`, `docs/` and `tests/` when applicable.
- After you added a new schema, command, etc., add the respective exports to index files at root of layers (std, utils, core, etc.)
